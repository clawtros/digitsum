[Comments]  (one comment per line)
a(19) = 102485 answers the classic puzzle of the area accessible to a walker constrained by digit sums (often posed with threshold 19).
Reachability has an exact characterization: writing x and y with k = floor(n/9) + 1 digits (most significant first), (x, y) with x, y >= 0 is reachable if and only if for every prefix length 1 <= s < k the prefix digit sums satisfy ds(x_prefix) + ds(y_prefix) <= n - 9*(k-s) + 1, and ds(x) + ds(y) <= n. Consequently a(n) is computed by a one-dimensional dynamic program over the walk d_s (see Program), in time polynomial in k.
The fraction of constraint-satisfying points that are reachable decays as c/sqrt(n) on the subsequence n == 8 (mod 9), where c = (6/sqrt(Pi)) * exp((1/2) * Sum_{m>=1} p_m/m) = 3.847174895..., with p_m the probability that a sum of 2m independent uniform digits equals 9m (a Sparre Andersen / Wiener-Hopf constant).
The base-2 analog of the quadrant version A401130 is A002054.

[Formula]
a(n) = 4*A401130(n) - 4*A051885(n+1) + 1, where A051885(n+1) = (r+1)*10^q - 1 with n+1 = 9*q + r, 1 <= r <= 9, is the least integer with digit sum n+1.

[Example]
For n = 1 the reachable points are (0,0), (+-1,0), (0,+-1): a(1) = 5. The point (2,0) is not counted for n = 1 since digitsum(2) = 2 > 1; the point (300,0) is not counted for n = 19 despite digitsum(300) = 3, because every path to it must pass the column |x| = 299 whose digit sum 20 exceeds 19.

[Program]
(Python)
def a(n, b=10):
    B = b - 1
    k = n // B + 1
    w = [0] * (2 * b - 1)
    for i in range(b):
        for j in range(b):
            w[i + j] += 1
    W = {B * k - n: 1}
    for s in range(k):
        cap = 1 if s < k - 1 else 0
        nxt = {}
        for d, c in W.items():
            for m, wm in enumerate(w):
                if d + m - B <= cap:
                    nxt[d + m - B] = nxt.get(d + m - B, 0) + c * wm
        W = nxt
    Q = sum(W.values())
    r = (n % B) + 1
    wall = (r + 1) * b ** ((n + 1 - r) // B) - 1
    return 4 * Q - 4 * wall + 1
